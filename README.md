# Keta Fitness Tracker

Static multi-page fitness tracker designed mobile-first.

Pages:
- Today
- Workouts
- Progress (includes calendar/history)
- Profile

No framework, build step, server, database, Firebase, Node.js or npm required.

Progress is stored with localStorage in the browser. The same GitHub Pages URL can be opened on phone or laptop; saved progress stays on the browser/device where it was recorded.
